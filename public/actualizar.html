Actualiza Caja Fantasma y conserva tu progreso

Desde la versión 1.25.0, la aplicación utiliza firmas nuevas. Si ya tienes 1.25.0 o superior, la actualización llega dentro de la aplicación.

Windows · versiones anteriores a 1.25.0

  1. Abre Configuración → Respaldo local → Exportar y guarda una copia.
  2. Usa Configuración → Windows → Descargar para PC o el botón de abajo. En las descargas, elige el archivo Caja-Fantasma-…-Instalador.exe.
  3. Ejecuta el instalador sobre tu copia actual y comprueba tus personajes, puntos, cajas e historial.

El instalador conserva la carpeta de datos. Después de este paso las actualizaciones llegarán dentro del programa.

Ver instalador de Windows

Android · versiones anteriores a 1.25.0

La nueva aplicación se instala junto a la anterior. Mantén la anterior instalada hasta comprobar tus datos.

  1. En la anterior abre Configuración → Respaldo local → Exportar.
  2. Descarga e instala Caja-Fantasma-Android-….apk.
  3. Abre la nueva aplicación, pulsa Importar respaldo y elige el archivo exportado.
  4. Comprueba personajes, puntos, cajas, rondas y módulos. Conserva ese archivo.

También puedes transferir el progreso desde Dispositivos. Conecta la aplicación anterior con el PC o la web, comprueba allí el historial y conecta después la nueva.

Ver descarga de Android

La web mantiene sus datos en el mismo navegador. Cierra y vuelve a abrir para cargar el diseño nuevo.
