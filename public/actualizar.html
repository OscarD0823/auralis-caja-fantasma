La versión nueva, con tu progreso

Desde la versión 1.25.0 hay un paso de instalación manual. Después podrás recibir las siguientes actualizaciones dentro de la aplicación.

Windows

  1. En tu aplicación actual abre Configuración → Respaldo local → Exportar y conserva el archivo.
  2. Descarga el instalador nuevo y ejecútalo sobre la aplicación actual.
  3. Abre la aplicación y comprueba tus personajes, puntos, cajas e historial.

El instalador conserva la misma carpeta de datos de Windows.

Android

La aplicación nueva se instala junto a la anterior. Mantén la anterior instalada hasta comprobar tus datos.

  1. En la anterior abre Configuración → Respaldo local → Exportar.
  2. Instala la nueva APK.
  3. Abre la nueva aplicación, pulsa Importar respaldo y elige el archivo exportado.
  4. Comprueba personajes, puntos, cajas, rondas y módulos. Conserva ese archivo.

Si necesitas otra forma de transferir, usa Dispositivos: conecta la aplicación anterior con el PC o la web, comprueba allí el historial y conecta después la nueva.

Descargar la versión nueva

La web mantiene sus datos en el mismo navegador. Cierra y vuelve a abrir para cargar el diseño nuevo.
