# Caja Fantasma 1.29.0

El contador cambia de Gravedad a Resonancia disonante **al comenzar el mantenimiento**, el **18 de noviembre de 2026 a las 18:00 de Colombia / 23:00 UTC / 15:00 PT**. El cambio no espera a que el juego vuelva a abrir y conserva el progreso.

- Aviso de fin de Gravedad con cuenta regresiva, visible en todas las pestañas. Se destaca durante las últimas 24 horas y desaparece al cambiar de rueda.
- Contador flotante desde la web mediante una ventana del navegador que permanece sobre otras ventanas. Funciona desde una pestaña o desde la web instalada, sin ejecutar el programa de PC.
- Puntero de color dentro de esa ventana, solo o junto al contador. Se conservan el color y el historial; abrir o cerrar la ventana no modifica puntos ni intentos.
- Botón **Instalar herramientas web**, instrucciones de instalación y acceso **Contador y puntero** desde los accesos de la aplicación web instalada.
- La ventana necesita un navegador de escritorio compatible y que la página o la web instalada siga abierta. El navegador no permite dibujar un punto transparente a los clics sobre un juego externo; el puntero web queda dentro de la ventana flotante.

Los puntos y el ciclo horario de S5 siguen pendientes de confirmación.

[Anuncio oficial de S5](https://www.oncehuman.game/news/devBlog/20261113/40781_1319568.html) · [Ventanas flotantes del navegador](https://developer.chrome.com/docs/web-platform/document-picture-in-picture)

Windows y Android mantienen las firmas actuales. Las instalaciones con las claves antiguas conservan la [guía de actualización manual](https://oscard0823.github.io/auralis-caja-fantasma/actualizar.html).
