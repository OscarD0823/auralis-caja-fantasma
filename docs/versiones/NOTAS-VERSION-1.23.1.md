# Caja Fantasma 1.23.1 · Auralis BETA

Se conserva el cofre original como logo en Windows, Android y la web. Esta es una actualización del mismo programa; mantiene su identificador, firma, preferencias y progreso. Repositorio y página pasan a las direcciones de Auralis. El autoguardado y la recuperación local se mantienen.

Se corrigió el manifiesto de descarga para las instalaciones antiguas de Android que mostraban «La APK no pertenece al repositorio oficial». El enlace de compatibilidad redirige al mismo archivo firmado de Auralis y conserva su SHA-256. No hace falta desinstalar ni borrar los datos de Caja Fantasma. Esta corrección de distribución no modifica la APK ni el instalador de Windows de esta versión.
