# Auralis Caja Fantasma 1.23.0 · BETA

Nueva identidad Auralis con iconos propios para Windows, Android y la web. La animación del cofre y sus recursos originales se conservan.

El progreso continúa guardándose en el dispositivo. Al ocultar o cerrar la aplicación se intenta completar también la copia local. Se mantienen los puntos, personajes, módulos, historial, conexiones y claves de almacenamiento anteriores.

Un apagado puede perder cambios posteriores a la última escritura completada. Exporta una copia para conservar un respaldo independiente.
