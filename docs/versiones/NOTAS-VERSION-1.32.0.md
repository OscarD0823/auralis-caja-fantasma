# Caja Fantasma 1.32.0

20 de noviembre de 2026 · Windows, Android y web.

En **Caja → Manibus → Guerras primigenias** elige **Normal**, **Difícil**, **Pro** o **Pesadilla / Apocalipsis**. Usa el botón **+** de cada caja que reclames. Cada caja suma **1 punto** y abrir las tres suma **3 puntos**. Los registros anteriores de Guerra Pro conservan los puntos con los que se guardaron.

En **Caja → Choque con el Prismaverso** registra **Eventos de crisis**. Cada recompensa que reclames suma **1 punto**.
