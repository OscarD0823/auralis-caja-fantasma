# Web 1.29.2

La versión web retira el puntero de la página, de la configuración y de la ventana flotante. El contador flotante sigue disponible.

Un botón **Descargar instalador de Windows** aparece en la barra superior y junto al contador. Descarga directamente el `.exe` de la última versión publicada; si la consulta a GitHub no está disponible, conserva un enlace verificado a la versión 1.29.1.

Esta publicación cambia exclusivamente la web. Las aplicaciones de Windows y Android siguen en 1.29.1, con sus funciones de puntero y sus firmas actuales. Los historiales, contadores y preferencias guardadas se conservan.
