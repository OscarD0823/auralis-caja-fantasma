# Caja Fantasma 1.31.2

18 de noviembre de 2026 · Windows, Android y web.

**Alegría, Ira, Lamento y Terror** ya se pueden registrar en **Caja → Resonancia discordante**. Pulsa **+** al reclamar la recompensa de un Movimiento para sumar **1 punto**.

Esta versión incluye el catálogo actualizado para que los cuatro botones estén disponibles desde la instalación. Incluye también el reloj de Resonancia discordante, el portal del Eco y las variantes de Ritmo.
