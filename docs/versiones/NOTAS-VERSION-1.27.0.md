# Caja Fantasma 1.27.0

- Los mapas muestran sus nombres completos según el idioma de la aplicación, incluyendo Sueño infinito, El camino del invierno e Islas del Abismo.
- Los jefes y las recompensas cambian de nombre al seleccionar otro idioma. El nombre original en inglés aparece al mantener el cursor sobre la tarjeta o el mapa. Para los idiomas sin traducción del juego se muestra el nombre original.
- Señor Hundido muestra sus fases con los nombres Búho de Calamidad, Torre de calamidad y Señor Hundido. Registra una vez la fase más alta alcanzada para sumar 1, 2 o 3 puntos.
- La prueba de voz confirma que empezó a reproducirse y muestra ayuda cuando el dispositivo requiere una voz o el navegador necesita permitir el sonido. El aviso utiliza el idioma elegido.
- Windows utiliza sus voces instaladas para avisar aunque la aplicación arranque minimizada.
- Android utiliza la voz nativa del teléfono y programa el aviso de Gravedad en segundo plano. En Configuración puedes autorizar avisos puntuales desde los ajustes de Android.
- En la web, pulsa Probar voz una vez y mantén la página abierta para recibir avisos.

Desde 1.25.0, las siguientes actualizaciones llegan dentro de la aplicación. Para Windows anterior a 1.25.0, exporta un respaldo y ejecuta el instalador actual sobre tu aplicación.
