# Caja Fantasma 1.25.0

Incluye el registro compacto por mapas de 1.24.0 y renueva las firmas de las aplicaciones tras perderse las claves anteriores al formatear el PC.

## Si ya usas Windows

Exporta un respaldo en **Configuración → Respaldo local → Exportar**. Descarga el instalador 1.25.0 y ejecútalo sobre la aplicación actual. Se conserva el identificador y la carpeta de datos de Windows. Después de esta instalación manual, las próximas actualizaciones llegarán desde el programa.

## Si ya usas Android

La nueva aplicación se instala junto a la anterior. Mantén la anterior instalada hasta comprobar la transferencia.

1. En la anterior, abre **Configuración → Respaldo local → Exportar**.
2. Instala la nueva APK e importa ese archivo mediante **Importar respaldo**.
3. Comprueba personajes, puntos, cajas, rondas y módulos. Conserva el archivo de respaldo.

También puedes pasar el progreso con **Dispositivos**, usando el PC o la web como copia intermedia. La aplicación anterior conserva sus datos mientras permanezca instalada.

La importación conserva los registros y aplica el catálogo más reciente disponible. Las versiones antiguas siguen consultando su canal anterior y no reciben automáticamente un paquete incompatible.

[Guía de transferencia](https://oscard0823.github.io/auralis-caja-fantasma/actualizar.html).

Referencias: [firmas y actualizaciones Android](https://developer.android.com/studio/publish/app-signing), [actualizador de Tauri](https://v2.tauri.app/plugin/updater/).
